📋 사용 방법

  1. 위 방 목록에서 테스트할 Draft를 클릭하거나 직접 Draft ID 입력
  2. "연결" 버튼을 클릭하여 WebSocket 연결
  3. Postman이나 다른 클라이언트로 로비 API 호출 (포지션 변경, 참가자 추가 등)
  4. 아래 메시지 영역에서 실시간 이벤트 수신 확인
테스트 가능한 이벤트: PARTICIPANT_JOINED, PARTICIPANT_LEFT, POSITION_CHANGED, ROLE_CHANGED, READY_STATUS_CHANGED, LEADER_POINT_CHANGED, INVITE_CODE_REFRESHED, DRAFT_STARTED
