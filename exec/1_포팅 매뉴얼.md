## 2. 빌드 및 배포 가이드

### 1) 환경 변수 설정
빌드 및 배포 시 아래 경로의 환경 변수 파일이 필요합니다.

#### Backend (`/etc/draft-go/Draft-Go-BE.env`)
```properties
# MySQL
MYSQL_URL=jdbc:mysql://localhost:3306/draft_go_db?...
MYSQL_USERNAME=...
MYSQL_PASSWORD=...

# MongoDB
MONGO_URI=mongodb://mongodb:27017/draft-go-db

# Redis
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=

# Riot API
RIOT_API_KEY=...
RIOT_API_MODE=REAL

# JWT
JWT_SECRET=...
JWT_ACCESS_TOKEN_VALIDITY_IN_SECONDS=1800
JWT_REFRESH_TOKEN_VALIDITY_IN_SECONDS=604800

# Profile
SPRING_PROFILES_ACTIVE=dev
```

#### Frontend (`/home/ubuntu/draft-go/Front/Draft-Go-FE/.env.production`)
```properties
VITE_API_BASE_URL=https://draft-go.com/api/v1
VITE_WS_URL=https://draft-go.com/ws
VITE_ENV_NAME=production
```

### 2) 빌드 및 배포 (Jenkins Pipeline)
Jenkins를 통해 자동화된 빌드 및 배포가 수행됩니다.

*   **Repository URL**: `https://lab.ssafy.com/s14-webmobile1-sub1/S14P11A205.git`
*   **Branch**: `dev`
*   **Pipeline Stages**:
    1.  **Checkout & Detect Changes**: Git Clone 및 변경 감지 (BE/FE 폴더)
    2.  **Backend Deploy**:
        *   `./gradlew clean build -x test` 실행
        *   기존 프로세스 종료 및 `nohup java -jar ...` 실행
        *   Health Check (`/actuator/health`) 수행
    3.  **Frontend Deploy**:
        *   `.env.production` 파일 복사
        *   `npm install` && `npm run build`
        *   Nginx 경로(`/var/www/draft-go-fe`)로 빌드 결과물(`dist/*`) 복사 및 Nginx 권한 설정

### 3) 수동 배포 (Fallback)
Jenkins 사용 불가 시 아래 명령어로 수동 배포 가능합니다.

**Backend**
```bash
cd Draft-Go-BE
./gradlew clean build -x test
nohup java -jar build/libs/draft-go-be-0.0.1-SNAPSHOT.jar --spring.config.location=/etc/draft-go/Draft-Go-BE.env &
```

**Frontend**
```bash
cd Draft-Go-FE
npm install
npm run build
sudo cp -r dist/* /var/www/draft-go-fe/
sudo systemctl reload nginx
```

### 4) Nginx 설정 (`/etc/nginx/sites-available/default` 등)
*   **HTTP -> HTTPS Redirect**: 80 포트 요청을 443으로 리다이렉트
*   **Static Files**: `/var/www/draft-go-fe` 디렉토리 서빙 (SPA Routing 지원)
*   **Reverse Proxy**:
    *   `/api/`, `/swagger-ui/` 등 -> `http://127.0.0.1:8080` (Backend)
    *   `/ws/` -> WebSocket 업그레이드 헤더 포함하여 Backend로 전달
    *   `/grafana/` -> `http://127.0.0.1:3001`
    *   `/kibana/` -> `http://127.0.0.1:5601`
    *   `/ai/` -> `http://127.0.0.1:8000` (FastAPI)
