## 1. 시연 개요

- 목적: Draft-Go 서비스의 핵심 기능(경매 드래프트, 전적 갱신, AI 분석) 시연
- 사전 준비: “루 안” 계정으로 미리 로그인 완료 상태
- 핵심 흐름: 마이페이지(전적 갱신) -> 방 생성 보여주기 -> 기존 방 입장(팀장) -> 경매 진행 -> 결과 확인 -> AI 분석

## 2. 상세 시나리오

### [Step 1] 마이페이지 및 전적 갱신

*(시연 시작 시점: 이미 로그인된 상태)*

1. **액션**: 상단 메뉴 [마이페이지] 클릭
2. **화면 설명**: 마이페이지 화면, 사용자 정보 및 전적 갱신 버튼 표시
3. **액션**: [전적 갱신] 버튼 클릭
4. **결과**: 전적 갱신 완료 메시지 확인 및 갱신된 전적 정보 표시

### [Step 2] 방 만들기 (간단히 보여주기만)

1. **액션**: 메인 화면으로 이동 후 [대회 생성하기] 버튼 클릭
2. **화면 설명**: 방 설정 모달 팝업 (방 제목, 설정 옵션 등)
3. **액션**: 내용 확인만 하고 [취소] 또는 모달 닫기
*(실제 방 생성은 하지 않음, UI만 보여주기)*

### [Step 3] 기존 방 입장 (팀장으로 시연)

1. **액션**: 메인 화면에서 미리 생성해둔 드래프트 방 목록 확인
2. **액션**: 시연용으로 준비된 방 클릭하여 입장
3. **화면 설명**: 대기실(Lobby) 화면
    - 팀장 슬롯, 팀원 슬롯, 채팅창 표시
    - 본인이 팀장으로 설정되어 있음 확인
4. **액션**:
    - 포지션 변경 기능 시연 (선택사항)
    - 모든 유저 [준비 완료] 상태 확인
    - 팀장으로서 [게임 시작] 버튼 클릭

### [Step 4] 경매 드래프트 진행 (유찰 큐 처리)

1. **화면 설명**: 경매 화면으로 전환, 선수 목록 및 타이머 표시
2. **액션**:
    - 경매 진행 과정 시연 (몇 차례 입찰)
    - 윈도우(탭 또는 창) 전환
3. **핵심 시연**:
    - 유찰 큐 1개가 남아있는 방으로 이동
    - 마지막 유찰 선수 입찰 진행
    - 마무리 입찰 완료

### [Step 5] 결과 확인

1. **화면 설명**: 경매 종료 후 결과 화면 자동 전환
2. **내용 확인**:
    - 최종 팀 구성 (Blue vs Red)
    - 각 선수 낙찰가 및 팀별 총 지출 예산
    - 포지션별 선수 배치

### [Step 6] AI 분석

1. **액션**: 결과 화면에서 [AI 분석] 버튼 클릭(우리팀 / 상대팀)
2. **화면 설명**: "AI가 전력을 분석 중입니다..." 로딩 표시
3. **결과 확인**:
    - 우리팀의 AI버튼
        - 우리팀 전력분석 및 key player 표시
        - 우리팀의 강점과 약점의 표시를 SWAT 분석의 틀을 차용
    - 상대팀의 AI버튼
        - 양팀의 전력분석 → 상대팀 파훼법 및 target player(구멍) 표시
        - 예상 승률 (예: 7:3 유리) 표시
        - 상대팀의 공략법에 대한 세부내용 표시
