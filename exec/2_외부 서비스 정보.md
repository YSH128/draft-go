# 2. 외부 서비스 정보

본 프로젝트에서 사용하는 외부 서비스 및 라이브러리에 대한 정보입니다.

## 1. Riot API
*   **용도**: 리그 오브 레전드 게임 데이터 조회 (챔피언, 소환사 정보, 전적 등)
*   **설정 방법**: `RIOT_API_KEY` 환경 변수에 유효한 API Key 등록 필요
*   **API Portal**: [https://developer.riotgames.com/](https://developer.riotgames.com/)
*   **주의사항**:
    *   개발용 Key는 24시간마다 만료되므로 갱신 필요
    *   배포 시 프로덕션(Service) Key 발급 권장

## 2. OpenAI API
*   **용도**: AI 모듈(`Draft-Go-AI`)에서 챔피언 추천 및 승률 분석 기능 제공
*   **설정 방법**:
    *   Backend/AI 모듈의 `.env` 또는 환경 변수에 `GMS_KEY` (또는 `OPENAI_API_KEY`) 설정 필요
    *   `GMS_BASE_URL` 설정 시 별도 게이트웨이 사용 가능
*   **사용 모델**: `gpt-4o` (또는 환경 변수 `AI_MODEL_NAME`으로 변경 가능)
*   **주의사항**: API 호출 비용 발생 가능
