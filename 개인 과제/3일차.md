## 4. 중괄호가 있는 JSX안에서 자바스크립트 사용하기

### 1) 따옴표로 문자열 전달하기

- 문자열 어트리뷰트를 JSX에 전달하려면 '' 나 "" 로 묶어야함

```
export default function Avatar() {
  return (
    <img
      className="avatar"
      src="https://i.imgur.com/7vQD0fPs.jpg"
      alt="Gregorio Y. Zara"
    />
  );
}
```

- 그러나 src와 alt를 동적으로 지정하려면 {} 사용

```
export default function Avatar() {
  const avatar = 'https://i.imgur.com/7vQD0fPs.jpg';
  const description = 'Gregorio Y. Zara';
  return (
    <img
      className="avatar"
      src={avatar}
      alt={description}
    />
  );
}
```

- 중괄호를 사용하면 마크업에서 바로 자바스크립트 사용 가능
