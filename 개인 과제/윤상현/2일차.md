# UI 표현하기

## 1. 첫 번째 컴포넌트

### 1) 컴포넌트 정의하기

- 기존에는 웹 페이지를 만들 때 웨 개발자가 컨텐츠를 마크업한 다음 JavaScript를 뿌려 상호작용을 추가
- React는 동일한 기술을 사용하면서 상호작용을 우선시
- React는 컴포넌트는 마크업으로 뿌릴 수 있는 JavaScript 함수

1. 1단계 컴포넌트 내보내기
   1. `export default` 접두사는 표준 JavaScript 구문
2. 2단계: 함수 정의하기

   1. `function Profile() { }`을 사용하면 `Profile`이라는 이름의 JavaScript함수를 정의 - 이름은 **대문자**로 시작

   ```jsx
   function Profile() {
     return (
       <img src="https://i.imgur.com/MK3eW3As.jpg" alt="Katherine Johnson" />
     );
   }

   export default function Gallery() {
     return (
       <section>
         <h1>Amazing scientists</h1>
         <Profile />
         <Profile />
         <Profile />
       </section>
     );
   }
   ```

3. 3단계 마크업 추가하기
   1. 이 컴포넌트는 `src` 및 `alt` 속성을 가진 `<img />` 태그를 반환
   2. `<img />`는 HTML처럼 작성되었지만 실제로는 JavaScript

### 2) 컴포넌트 사용하기

```jsx
function Profile() {
  return <img src="https://i.imgur.com/MK3eW3As.jpg" alt="Katherine Johnson" />;
}

export default function Gallery() {
  return (
    <section>
      <h1>Amazing scientists</h1>
      <Profile />
      <Profile />
      <Profile />
    </section>
  );
}
```

- `<section>`은 소문자이므로 React는 HTML태그를 가리킨다고 이해
- `<Profile />`은 대문자 `p`로 시작하므로 React는 `Profile`이라는 컴포넌트를 사용하고자 한다고 이해

1. 컴포넌트 중첩 및 구성
   1. Gallery는 각 Profile을 “자식”으로 랜더링하는 **부모 컴포넌트**
2. 컴포넌트는 다른 컴포넌트를 랜더링할 수 있지만, 그 정의를 중첩해서는 안됌
   1. 최상위 레벨에서 컴포넌트를 정의해야함
   2. 자식 컴포넌트에서 부모 컴포넌트의 일부 데이터가 필요한 경우, 정의를 중첩하는 대신 **props**로 전달
3. 컴포넌트의 모든 것
   1. React 애플리케이션은 “root” 컴포넌트에서 시작. CodeSandbox 또는 Next.js를 사용하는 경우 root 컴포넌트에서 pages/index.js 에 정의
   2. 대부분의 React 앱은 모든 부분에서 컴포넌트를 사용
   3. 컴포넌트는 한 번만 사용되더라도 UI 코드와 마크업을 정리하는 편리한 방법

## 2. 컴포넌트 import 및 export 하기

### 1. Root 컴포넌트란

- 위의 예시 코드 컴포넌트들은 모두 App.js 라는 root 컴포넌트 파일에 존재
- 설정에 따라 root 컴포넌트가 다른 파일에 위치할 수도 있음
- Next.js처럼 파일 기반으로 라우팅하는 프레임워크일 경우 페이지별로 root 컴포넌트가 다를 수 있음

### 2. 컴포넌트를 import하거나 export 하는 방법

1. 컴포넌트를 추가할 JS 파일 생성
2. 새로 만든 파일에서 함수 컴포넌트를 **export** 합니다. ([default](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Statements/export#using_the_default_export) 또는 [named](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Statements/export#using_named_exports) export 방식을 사용)
3. 컴포넌트를 사용할 파일에서 **import** 합니다. (적절한 방식을 선택해서 [default](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Statements/import#importing_defaults) 또는 [named](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Statements/import#import_a_single_export_from_a_module)로 import)

```jsx
1. App.jsx

import Gallery from './Gallery.jsx';

export default function App() {
    return (
        <Gallery />
    )
}

2. Gallery.jsx

function Profile() {
    return (
        <img
            src="https://i.imgur.com/QIrZWGIs.jpg"
            alt="Alan L. Hart"
        />
    );
}

export default function Gallery() {
    return (
        <section>
            <h1>Amazing scientists</h1>
            <Profile />
            <Profile />
            <Profile />
        </section>
    );
}
```

- App.jsx 파일에서 Profile과 Gallery 컴포넌트를 빼서 새로운 Gallery.jsx 파일로 옮김. Gallery는 Gallery.js 에서 import 해서 사용 가능

| Syntax  | Export 구문                           | Import 구문                             |
| ------- | ------------------------------------- | --------------------------------------- |
| Default | `export default function Button() {}` | `import Button from './button.js';`     |
| Named   | `export function Button() {}`         | `import { Button } from './button.js';` |

- 한 파일에서 하나의 컴포넌트만 export 할 때 default export 방식
- 여러 컴포넌트를 export 할 경우 named export 방식 사용
- 컴포넌트와 파일의 이름을 의미 있게 명명하는 것이 중요

### 3. 한 파일에서 여러 컴포넌트를 import 하거나 export 하는 방법

- 전체 갤러리가 아니라 하나의 profile 만 사용하고 싶을 때 Proifle 컴포넌트만 export 하면된다. 그러나 Gallery.jsx 파일에는 이미 하나의 default export가 존재하기 때문에 두 개의 default export를 정의할 수 없음
  - 새로운 파일 하나를 더 생성해서 default export를 사용하거나 named export로 Profile 컴포넌트를 export 할 수 있음

### 4. 컴포넌트 한 단계 더 분리하기

1. named 방식

   ```jsx
   1. App

   import Gallery from './Gallery.js';
   import { Profile } from './Profile.js';

   export default function App() {
     return (
       <div>
         <Profile />
         <Gallery />
       </div>
     );
   }

   2. Gallery
   import { Profile } from './Profile.js';

   export default function Gallery() {
     return (
       <section>
         <h1>Amazing scientists</h1>
         <Profile />
         <Profile />
         <Profile />
       </section>
     );
   }

   3. Profile
   export function Profile() {
     return (
       <img
         src="https://i.imgur.com/QIrZWGIs.jpg"
         alt="Alan L. Hart"
       />
     );
   }
   ```

2. default 방식

   ```jsx
   1. App
   import Gallery from './Gallery.js';
   import Profile from './Profile.js';

   export default function App() {
     return (
       <div>
         <Profile />
         <Gallery />
       </div>
     );
   }

   2. Gallery
   import Profile from './Profile.js';

   export default function Gallery() {
     return (
       <section>
         <h1>Amazing scientists</h1>
         <Profile />
         <Profile />
         <Profile />
       </section>
     );
   }

   3. Profile
   export default function Profile() {
     return (
       <img
         src="https://i.imgur.com/QIrZWGIs.jpg"
         alt="Alan L. Hart"
       />
     );
   }
   ```
