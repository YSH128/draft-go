1. App.js
    1. 컴포넌트 생성
    2. 컴포넌트는 재사용 가능한 코드 조각
    3. 애플리케이션의 UI 엘리먼트를 랜더링 관리, 업데이트 할 때 사용
        
        ```jsx
        export default function Square() {
          return <button className="square">X</button>;
        }
        ```
        
    4. `export`
        1. 함수를 파일 외부에서 접근할 수 있도록 함
        2. default 키워드는 코드를 사용하는 다른 파일에서 이 함수가 파일의 주요 함수임을 표시
    5. `return`: 버튼을 반환
    6. `className=”square”`: 버튼 Prop 또는 프로퍼티. CSS에 버튼의 스타일을 지정하는 방법을 알려줌
2. index.js
    1. App.js 파일에서 만든 컴포넌트와 웹 브라우저 사이의 다리 역할
3. <>  </>
    1. 현재는 사각형이 1개인데, 컴포넌트는 단일 JSX 엘리먼트를 반환
    2. Fragment를 사용하여 여러 개의 JSX 엘리먼트를 반환할 수 있음  
4. Props를 통해 데이터 전달하기
    1. 사용자가 사각형을 클릭할 때 사각형의 값을 비어있는 상태에서 “X”로 변경해야함
    2. Board 컴포넌트에 Square 컴포넌트 삽입
        
        ```jsx
        export default function Board() {
            return (
                <>
                    <div className="board-row">
                        <button className="square">1</button>
                        <button className="square">2</button>
                        <button className="square">3</button>
                    </div>
                    <div className="board-row">
                        <button className="square">4</button>
                        <button className="square">5</button>
                        <button className="square">6</button>
                    </div>
                    <div className="board-row">
                        <button className="square">7</button>
                        <button className="square">8</button>
                        <button className="square">9</button>
                    </div>
                </>
            );
        }
        
        ==>
         <>
              <div className="board-row">
                <Square />
                <Square />
                <Square />
              </div>
              <div className="board-row">
                <Square />
                <Square />
                <Square />
              </div>
              <div className="board-row">
                <Square />
                <Square />
                <Square />
              </div>
            </>
        
        ```
        
    3. 새로운 문제: 각 사각형이 “1”로 표시 → Props를 사용하여 각 사각형이 가져야 할 값을 부모 컴포넌트(Board)에서 자식 컴포넌트(Square)로 전달 ⇒ Square 컴포넌트를 Board에서 전달할 value를 읽도록 수정

        ```jsx
        function Square({value}) {
            return <button className="square">{value}</button>
        }
        ```
