# Day 2: Figma 학습 (2026-01-13)

## 1. Figma란?

### 주요 특징

- **인터페이스 기획 디자인 전문** 온라인 UI/GUI 디자인 프로그램
- **디지털 프로젝트 콜라보레이션** 프로그램
- 웹 브라우저와 데스크톱 앱 모두 지원

---

## 2. Figma 서브 프로그램

1. **Figma Design** (메인)
2. **FigJam** - 협업 화이트보드
3. **Figma Slides** - 프레젠테이션 도구
4. **Figma Buzz** - 커뮤니케이션
5. **Figma Sites** - 웹사이트 제작
6. **Figma Make** - AI기능 제작 도구

---

## 3. Figma 주요 기능

### 3.1 인터페이스 전문 기능

- **Component-Variants-Design System**

  - 재사용 가능한 컴포넌트 시스템
  - 변형 관리를 통한 일관성 유지
  - 디자인 시스템 구축

- **고유의 UI/GUI 디자인 전문 기능**
  - **벡터 네트워크**: 복잡한 벡터 그래픽 작업
  - **오토 레이아웃**: 반응형 디자인 자동화

### 3.2 Figma 프로토타이핑

- 인터랙티브 프로토타입 제작
- 화면 전환 및 애니메이션 설정
- 사용자 흐름 시뮬레이션

---

## 4. 포토샵 vs Figma

| 구분           | 포토샵             | Figma               |
| -------------- | ------------------ | ------------------- |
| **용도**       | 비트맵 이미지 편집 | UI/UX 디자인        |
| **협업**       | 파일 공유 방식     | 실시간 협업         |
| **환경**       | 데스크톱 앱        | 웹 브라우저 + 앱    |
| **프로토타입** | 제한적             | 강력한 프로토타이핑 |

---

## 5. Figma를 통한 워크프로세스 변화

### 기존 프로세스

디자인 → 파일 공유 → 피드백 → 수정 → 재공유

### Figma 프로세스

실시간 협업 디자인 → 즉시 피드백 → 동시 수정 → 버전 관리

**주요 변화점**

- 실시간 동시 작업 가능
- 버전 히스토리 자동 관리
- 개발자 핸드오프 간소화
- 클라우드 기반 자동 저장

---

## 6. Figma 인터페이스 구성

### 기본 구조

```
레이어 패널 - 작업화면 - 프로퍼티스 패널
```

1. **레이어 패널** (좌측)

   - 프로젝트 구조 확인
   - 레이어 관리 및 정렬

2. **작업 화면** (중앙)

   - 디자인 작업 공간
   - 캔버스 및 프레임 작업

3. **프로퍼티스 패널** (우측)
   - 선택한 요소의 속성 편집
   - 스타일, 레이아웃 설정
