# Nginx 기초 이해

## 1. Nginx의 주요 역할
Nginx는 가볍고 높은 성능을 자랑하는 웹 서버이자 역방향 프록시(Reverse Proxy) 서버이다. 백엔드 구성에서 주로 다음과 같은 용도로 사용된다.
- **역방향 프록시**: 클라이언트의 요청을 받아 내부 네트워크의 백엔드 서버로 전달한다.
- **로드 밸런싱**: 여러 대의 백엔드 서버로 트래픽을 분산시킨다.
- **SSL 종단점(SSL Termination)**: HTTPS 인증서를 Nginx에 설정하여 백엔드 서버 대신 암호화 복호화 처리를 담당한다.
- **정적 리소스 서빙**: 이미지, HTML 등 변하지 않는 파일을 백엔드 로직 없이 직접 빠르게 반환한다.

## 2. 주요 설정 파일 경로(Ubuntu 기준)
- **설정 파일 위치**: /etc/nginx/nginx.conf(전체 기본 설정)
- **사이트별 설정**: /etc/nginx/sites-available/
- **활성화된 설정**: /etc/nginx/sites-enabled/
- **로그 파일**: /var/log/nginx/access.log (접속 로그), error.log(에러 로그)

## 3. 핵심 설정 블록 예시 (Reverse Proxy)
가장 일반적인 Nginx -> Spring Boot(8080) 연결 설정입니다.
```
server {
    listen 80;
    server_name draft-go.com;

    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## 4. 필수 명령어
설정 변경 후에는 반드시 문법 검사(-t) 후 재시작(reload)하는 습관이 중요하다.
- `sudo nginx -t`
    - 설정 파일의 문법이 올바른지 확인
- `sudo systemctl reload nginx`
    - 서비스를 중당하지 않고 변경된 설정만 반영
- `sudo systemctl restart nginx`
    - Nginx 서비스를 완전히 재시작
- `sudo systemctl status nginx`
    - Nginx 실행 상태를 확인

## 5. 추가 팁
- **무중단 배포**: Nginx의 `upstream` 설정을 활용하면 백엔드 서버를 여러 개 띄워 무중단 배포 환경 구성 가능
- **보안**: Nginx 설정만으로 특정 IP 차단이나 요청 크기 제한(client_max_body_size) 등을 처리하여 백엔드 서버 부담 감소
