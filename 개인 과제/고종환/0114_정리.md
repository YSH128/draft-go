# EC2 환경에서 Nginx 세팅 방법

## Phase 1. 인프라 준비
Nginx를 설치하기 전, 외부에서 접속이 가능하도록 보안 그룹(Security Group) 설정이 선행되야한다.
- 인바운드 규칙 편집
    - HTTP (80): `0.0.0./0`(전체 허용)
    - HTTPS (443): `0.0.0./0`(전체 허용)
    - SSH (22): 내 IP

## Phase 2. Nginx 설치 및 실행
EC2에 SSH로 접속한 후 다음 명령어를 순서대로 실행합니다.
1. 패키지 업데이트 및 설치
    ```bash
    # 패키지 매니저 업데이트
    sudo apt update
    # Nginx 설치
    sudo apt install nginx -y
    # 설치 버전 확인
    nginx -v
    ```
2. 상태 확인 및 서비스 활성화
    ```bash
    # Nginx 상태 확인 (Active: active (running) 확인)
    sudo systemctl status nginx
    # 서버 재부팅 시 Nginx 자동 실행 설정
    sudo systemctl enable nginx
    ```
## Phase 3. 접속 확인
1. AWS 콘솔에서 해당 EC2의 퍼블릭 IPv4 DNS를 복사합니다.
2. 브라우저 주소창에 입력하고 접속합니다.
3. "Welcome to nginx!" 페이지가 보이면 성공입니다.

## Phase 4. 백엔드 연동 기초 설정 (Reverse Proxy)
1. 설정 파일 생성
    ```bash
    sudo vi /etc/nginx/sites-available/my-project.conf
    ```
2. 설정 내용 작성 (Basic)
    ```nginx
    server {
        listen 80;
        server_name [본인_도메인_또는_IP];

        location / {
            proxy_pass http://localhost:8080; # 백엔드 서버
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
        }
    }
    ```
3. 심볼링 링크 생성 (설정 활성화)
    Ubuntu 관례에 따라 `sites-enabled` 폴더에 링크를 생성합니다.
    ```bash
    # 기존 기본 설정 삭제 (선택)
    sudo rm /etc/nginx/sites-enabled/default
    # 내 설정 활성화
    sudo ln -s /etc/nginx/sites-available/my-project.conf /etc/nginx/sites-enabled/
4. 검사 및 반영
    ```bash
    # 설정 파일 문법 검사
    sudo nginx -t
    # 설정 반영
    sudo systemctl reload nginx
    ```
